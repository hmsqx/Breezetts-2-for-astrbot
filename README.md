# Breeze TTS 与歌曲翻唱插件 v1.9.0

普通语音、歌曲收录、整首与高潮翻唱，以及本机服务管理，集中在一个插件中。

## 安装插件

在 AstrBot「插件 → 安装插件 → 从链接安装」中填写：

```text
https://github.com/hmsqx/Breezetts-2-for-astrbot
```

当前版本面向 **Windows x64、NVIDIA CUDA、本机 AstrBot 4.29.3 及以上的 4.x 版本**，已验证 QQ / OneBot v11。Linux、macOS、容器部署及远程服务控制尚未适配。普通语音和翻唱的一键安装使用固定的 `D:/Echok` 目录，需要可写的 D 盘及足够磁盘空间。安装插件后，仍需在「语音服务」页面安装模型与后端，再分别启动服务。

仓库只包含插件、管理页、测试及配套后端源码，不包含模型权重、参考音色、个人配置或歌曲音源。首次使用请自行设置参考音频与准确原文；安装插件不会自动生成音频。

## 怎样唱歌

- “唱完整首《歌名》，用语音发给我。” → `sing_song(name)`，默认按自然停顿连续发送多条语音。
- “唱《歌名》的高潮。” → `sing_song_clip(name)`，联网核对同步歌词，由当前会话模型选择完整副歌。
- “唱第90秒到160秒。” → `sing_song_clip(name, start_seconds=90, end_seconds=160)`。
- “整首作为文件发给我。” → `sing_song(name, delivery="file")`。
- 片段也能明确选择 `delivery="file"`；不填写时始终为 `voice`。

整首与片段是音频范围，语音与文件是发送方式，两者独立。整首与手动时间范围不需要歌词；只有自动选高潮需要时间轴。整首语音同样保留全部音频，不会只唱前一分钟。

语音只在检测到的人声停顿处分条，不固定每15秒切割。单条最多60秒，20–45秒只是偏好，必要时允许较短的首尾段。若整段存在超过60秒且没有可靠停顿的区域，会在发送任何分段前明确失败，不切断唱词，也不自动改发文件。需要文件时由用户明确选择。

“学歌”是收录音源并保留旋律转换声线，不训练模型。只能收录来源实际可获取的音频，来源只有试听时不能称为完整歌曲。最多支持10分钟。

## 启动与配置

在同一个「语音服务」页面，普通语音与翻唱各提供「一键安装」按钮。支持当前 Windows x64 本机服务目录，需要 Python 3.12（可复用 AstrBot 自带的 3.12）。插件附带配套后端源码，自动补齐缺失文件，无需手动搬源码；已有源码和自定义修改不覆盖。Seed-VC 必要源码与许可证也随插件附带（约194 KiB压缩包，固定提交并校验），正常安装无需访问 GitHub，也无需 Git。附带包漏装或损坏时才尝试固定版本的 GitHub 原包。其他操作系统和自定义服务目录尚不支持。

先关闭普通语音和翻唱两个服务，等歌曲任务结束，再点击安装。页面会提示未满足的前提；另一服务仍运行时也会禁用安装按钮。首次普通语音建议预留16 GiB、翻唱12 GiB，用于模型、CUDA依赖和下载缓存；已有模型时至少检查2 GiB余量。这是预检阈值，实际占用仍取决于缓存与已有环境。

安装在后台执行，显示阶段、用时、当前文件的下载量/速度和日志；无法测量的步骤使用不定进度。刷新或关闭页面不会停止后台安装。网络中断最多自动尝试3次，模型下载及清单查询会尝试官方站和 hf-mirror.com；已知大小文件支持续传，权重经校验后复用，损坏的JSON配置重新下载。点击「停止安装」会结束安装进程树并保留已完成文件，随后可点「继续安装 / 修复」。失败会自动展开日志，不需从头下载全部模型。

两张服务卡上方的「安装与下载来源」集中提供三个下拉框：Python依赖、CUDA/PyTorch、模型权重。默认自动换源；手动指定后只使用所选源，失败也不会偷偷换回其他源。选项保存在当前浏览器，安装期间锁定，并随安装请求固定到后台任务。浏览器不允许本地存储时会提示只在本次页面有效。「恢复自动」可一键恢复全部自动策略。该选择只影响安装，不修改音色或运行中的服务。

自动模式下，普通Python依赖依次尝试清华、阿里云、PyPI官方源；CUDA依赖依次尝试阿里云轮子目录（普通依赖使用已选Python源，默认清华）、上海交大CUDA镜像、PyTorch官方源，始终保留 `2.9.1+cu128` 版本约束。模型可选HF国内镜像、官方或自动切换。进度显示实际来源与尝试次序。配置仅作用于安装子进程，不修改电脑的pip配置，也不继承其他额外索引或禁用索引选项。[清华源说明](https://mirror.tuna.tsinghua.edu.cn/help/pypi/)、[交大CUDA源说明](https://mirrors.sjtug.sjtu.edu.cn/docs/pytorch-wheels)、[阿里云CUDA目录](https://mirrors.aliyun.com/pytorch-wheels/cu128/)。

人声分离模型的上游不可用时尝试模型仓库副本，并使用与原文件相同的完整SHA-256校验；该副本也会尝试HF镜像。FFmpeg优先复用已有工具，缺失时从Gyan下载，失败再尝试FFmpeg官网列出的BtbN独立构建。换源无法解决所有网络都不可达、磁盘不足、依赖冲突或DLL缺失，失败原因保留在安装日志中。

开发者刷新离线Seed源码时，可运行 `python plugin/bundle_runtime.py <固定版本原始zip路径>`；脚本核对原包SHA-256，只收录代码、配置与许可证，不打包示例音频或模型。

新环境不继承系统Python依赖，并明确安装匹配的CUDA 12.8版PyTorch/torchaudio；旧环境保留，不自动重建。翻唱仅安装当前Whisper+BigVGAN路径所需依赖，不再安装未使用的DAC及其额外依赖链，已有环境中的可选包不卸载。完成前会离线检查实际模块导入、CUDA编译版本、音频工具和模型文件；检查失败不会显示成功。导入检查屏蔽GPU，不加载模型或验证推理。安装不会自动启动服务、生成音频，也不删除歌库和音色配置；插件重载会中断安装，文件保留。

普通语音安装到自己的 `.venv`，启动时优先使用该环境，原有系统 Python 保留作未安装时的兼容入口。音频工具放在 `D:/Echok/tools/ffmpeg/bin` 并加入插件启动服务的进程 PATH。安装文件准备完成不代表推理已验证，之后请分别点击原有启动按钮。

遇到DLL加载错误时查看日志末尾，检查NVIDIA驱动与Microsoft VC++运行库；依赖或网络问题修复后继续安装。安装器不自动安装系统驱动。现有后端文件若已损坏且需要覆盖，请先核对自定义修改；自动补齐只处理缺失文件。

在 AstrBot 插件列表打开 Breeze →「语音服务」，分别启动普通语音和翻唱服务。页面提供各自的关闭按钮、模型状态、歌曲任务进度和完整配置表单。服务已运行时会复用；任务进行中禁止关闭。

普通自动语音还需在 AstrBot 语音设置启用 TTS，选择 Breeze TTS。`/breeze_sample 你好` 可试听当前音色；`/breeze_status` 查看当前状态。

可视化表单与 AstrBot 原插件配置共用一份设置：音色描述、CFG、种子、参考音频及原文、克隆引导，以及两种服务的连接、超时、重试和翻唱启用项。保存只影响后续请求，不自动启停服务。参考音频路径是本机文件路径；配置被其他入口修改时会拒绝覆盖旧版本。

参考音频须为完整的1–30秒PCM WAV；克隆需要填写准确原文。支持语音设计、纯克隆及克隆时的语气引导。

宽屏页面左右分栏，左侧任务/服务/歌库、右侧配置；窄窗口自动单列。任务执行时每3秒刷新，空闲时每5秒刷新。查询和转换阶段显示真实阶段与用时，无法测量时不编造百分比；发送按已确认条数显示。

## 歌曲库

源音频永久保存在 `D:/Echok/breeze-cover/data/songs/`，不会参与临时语音自动清理。

管理页可上传本地WAV、MP3、M4A、AAC、FLAC、OGG、OPUS、MP4和WebM，填写歌名、可选实际歌手及语言。单文件最多120MiB、音频最长10分钟；后台直连接口上限200MiB。上传后校验并正规化，不覆盖同名歌曲，不修改电脑上的原文件。

联网收录由模型先搜索可访问的音频/受支持页面，再调用 `learn_song`；已确认实际演唱者时保存 `artist`，不把视频上传者当歌手。同名歌曲复用会明确通知，已知歌手冲突则拒绝并提示使用包含歌手的新名称。

每首歌可点「删除音源」，页面确认完整歌名后仅删除该歌曲及其时间轴缓存；也可由 AstrBot 管理员明确说“删除已收录的《歌名》”。上传、翻唱或识别任务中禁止删除，不为了清理空间或重试而自动删源。

## 自动选高潮

先查询LRCLIB，再尝试网易云公开歌曲/歌词接口；无可靠在线时间轴才使用当前音源的临时CPU Whisper识别。LRCLIB瞬时连接错误、超时或502/503/504最多重试一次，总上限18秒，401/403/429不重试。

匹配核对歌名、语言、歌手、录音版本和时长（允许差值2秒）。相近时长的多份歌词只有在不同记录形成明显一致群时才解歧；不能用多数票混用不同歌手、现场或翻唱版本。来源标题仅在严格《相同曲名》-歌手-MV格式下提供临时查询线索，不写回已核验歌手。旧音源也可直接说“唱周杰伦《反方向的钟》的高潮”来提供明确歌手。

歌词字段只有制作署名或纯文本时不当作同步歌词。模型只能选择带时间的连续歌词行，不固定截取30秒，不猜偏移。歌词和本地识别都是时间轴候选，并非对录音做了精确强制对齐，歌声识别与模型判断仍可能有误。

本地识别独立CPU子进程结束后释放内存，不占GPU、不暂停普通TTS；实际进入GPU翻唱才暂停TTS，完成、失败或取消后恢复。识别结果按源文件身份与语言缓存，失败不缓存。QQ只发音频和简短结果，检索、识别、选段和错误细节留在管理页/日志。

## 服务与临时文件

默认普通TTS为 `127.0.0.1:7860`，翻唱后台为 `127.0.0.1:7861`。当前显存无法同时运行两套模型，后台会在转换前安全暂停TTS、转换后恢复。

从插件启动的服务及转换后代绑定AstrBot生命周期；退出AstrBot会关闭，插件热重载会保留。独立启动且仅被复用的外部服务保留外部归属，页面明确显示。只关管理网页不等于退出AstrBot。

普通TTS和翻唱会清理 `breeze_tts_*.wav`：保留最新50个，额外且超过24小时的旧文件删除。原始歌库不自动删除；后台输出在传输后释放。部分语音发送失败不会自动重发，防止重复。

## 工具

| 工具 | 用途 |
| --- | --- |
| `set_voice_clone(ref_audio_path, ref_text)` | 设置参考音色 |
| `set_voice_design(instruction, cfg_scale)` | 设置设计音色 |
| `speak(text)` | 普通语音 |
| `learn_song(name, url, artist="")` | 后台永久收录 |
| `list_learned_songs()` | 列出歌库 |
| `delete_song(name)` | 管理员明确请求后逐首删除 |
| `sing_song(name, delivery="voice")` | 整首，默认连续语音；明确选择file则发文件 |
| `sing_song_clip(name, start_seconds=-1, duration_seconds=0, end_seconds=-1, artist="", delivery="voice")` | 自动高潮或指定片段，与发送方式独立 |

## 开发与验证

入口已拆为框架注册薄壳，配置、TTS、任务状态、歌库、控制台、翻唱和语音发送各自独立。模块职责、扩展步骤与测试命令见 [ARCHITECTURE.md](ARCHITECTURE.md)。

已有离线回归覆盖安装恢复与换源、配置冲突保护、WAV 完整性、歌曲工具、自然停顿分段以及管理页交互。运行框架相关测试需要可导入 AstrBot；源码开发环境可通过 `ASTRBOT_SOURCE` 指定 AstrBot 源码根目录。

模型生成与真实聊天投递需要使用你自己的音色、音源和账号单独验证，离线测试通过不代表任意硬件、网络及平台均已验证。

## 上游项目与许可

- [Seed-VC](https://github.com/Plachtaa/seed-vc)：翻唱声线转换；随附固定版本的源码与原始许可证保存在 `runtime/seed-vc.zip`，版本与校验值记录在 `runtime/seed-vc.json`。
- 模型权重由安装器从其公开来源下载，不随本仓库分发；使用前请阅读相应上游模型与代码许可。
